# DEAlignAI CRACK Surgery Reference

This directory contains the published `CRACK_SURGERY.json` recipe from:

- Model: `dealignai/GLM-5.3-CYBERSECURITY-FP8`
- Source: https://huggingface.co/dealignai/GLM-5.3-CYBERSECURITY-FP8
- Original recipe: `CRACK_SURGERY.json`

The file is preserved as an external research reference for AegisForge
model-surgery experiments.

It is NOT an AegisForge-developed model recipe.

AegisForge may use this artifact as a baseline/reference for studying
model-surgery techniques and for developing independently evaluated
security-specialized model methods.

See the original Hugging Face repository for the authoritative version
and licensing information.
