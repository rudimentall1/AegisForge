# AegisForge — правила работы

1. Работай в своих файлах: Agent A — shared/, tests/; Agent B — orchestrator/, agents/.
2. Коммить и мержить можно самостоятельно, без ожидания approval.
3. Нашёл баг в чужом коде — напиши комментарий в PR и продолжай свою работу, не жди исправления.
4. Не знаешь, что делать — пиши в issue и делай то, что можешь без ответа.
